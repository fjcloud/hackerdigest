## Top Stories

### [Jellyfin 12.0](https://news.ycombinator.com/item?id=49604861)
The FOSS Plex alternative ships after seven release candidates and a troubled 10.11 line. Migrating a 40TB library took minutes. Top commenters argue the project is shipping comic-book support and performance work before basic internet-facing hardening, which they call a priority mistake.

### [Factored the RSA keys of a 90s Certificate Authority](https://news.ycombinator.com/item?id=49604637)
A weekend project factored 512-bit RSA roots baked into Netscape Communicator 4.51, then issued valid certs against them from a retro server. The author admits LLM-written extraction scripts are not fully verified. Top replies asked when consumer GPUs will crack 1024-bit, and noted CADO-NFS leaves GPU speedups on the table.

### [Broadcom pulls VDDK downloads](https://news.ycombinator.com/item?id=49602699)
The VMware Disk Development Kit is now NDA-only for backup vendors, making third-party migration tools harder to build. Former VMware engineers called it part of Broadcom's controlled descent. VMware-to-Proxmox moves remain reportedly painless; only the reverse direction was already hard.
