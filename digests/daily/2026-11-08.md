## Top Stories

### [Every Mac comes with an (undocumented) family member classifier](https://news.ycombinator.com/item?id=50403097)
Since macOS 2022, daemons silently build a social graph from Messages, Photos, and Contacts -- inferring relationships, co-appearance networks, and race from face clusters. Data lives in `~/Library/IntelligencePlatform` as unencrypted SQLite, protected only by TCC. It persists with Apple Intelligence and Siri disabled. No documented opt-out exists; commenters lock the directory with `chflags schg` as a workaround.

### [Claude Code's "Don't Ask Again" exposes passwords in 1,122 public GitHub files](https://news.ycombinator.com/item?id=50407882)
Approving a command with secrets and checking "Don't Ask Again" writes the raw command to `.claude/settings.local.json`, which Claude then auto-commits. Anthropic says the file is gitignored by default but users manually commit it. Fix: secret scanning (GitHub, git-secrets) and never committing `.claude/`. Thread consensus: user error amplified by tooling that makes leaking effortless.

### [The end of Microsoft Research's AI Frontiers group](https://news.ycombinator.com/item?id=50406563)
John Langford's 50-person fundamental research group was disbanded in a broader MSR reorg under Azure Security. Langford argues the "basic deal" -- do good work, good things happen -- is broken; leadership prioritizes transformer scaling over exploratory research. Commenters note this mirrors Meta firing Yann LeCun's exploratory faction. Counter-argument: Chinchilla laws show diminishing returns; "good enough and cheap" may win.

### [What I run on my $10 OpenStick homelab](https://news.ycombinator.com/item?id=50406670)
A 4G dongle (MSM8916, 480MB RAM) runs Debian with AdGuardHome, ZeroClaw (AI agent), Fusion (RSS), and monitoring in ~400MB. Backups via restic to Backblaze. Thread notes: Chromeboxes (~$200) offer more compute; Podman auto-update handles containers; security concerns about giving an LLM agent root shell on a network-exposed device.
