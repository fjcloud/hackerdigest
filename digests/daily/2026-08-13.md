## Top Stories

### [Tailscale Traces Database Corruption to 16y/o SQLite WAL-Reset Bug](https://news.ycombinator.com/item?id=49272832)
A rare race in SQLite's checkpoint code caused control-plane corruption at Tailscale. The bug existed for 16 years because almost nobody hits it -- Tailscale did only because they manually run aggressive checkpoints for backup speed. SQLite funded a VFS shim to reproduce the race deterministically. The thread's sharpest observation: SQLite has 92 million lines of tests and still missed this; the same class of race could exist in Postgres's checkpointer.

### [Zed launches Delta, a multiplayer agent editor](https://news.ycombinator.com/item?id=49276574)
A standalone app for shared AI-coding sessions with inline annotations on agent output. The skeptical consensus: this looks like a VC-driven pivot away from fixing long-standing Zed editor bugs. One commenter noted the multi-year transcript approach inverts the ADR model by treating chat logs as the durable decision record.

### [uBlock Origin gives up fighting Facebook ads](https://news.ycombinator.com/item?id=49270726)
Maintainers say Facebook's randomized class names and eight-deep div soup have made selector-based blocking unsustainable. The strongest thread counter-argument: the only durable fix is server-side HTML stripping, since the underlying problem is an ad-tech arms race uBlock cannot win.

### [Mass vuln scans spoofing AI bot user agents](https://news.ycombinator.com/item?id=49272569)
A surge of scans are pretending to be ClaudeBot, GPTBot, and friends, mostly from Google Cloud IP space. One operator in the thread built an ASN-based reputation system with custom risk scoring, cutting 20% of their traffic with negligible false positives.
