### [Hackers activate automatic defrosting in supermarket fridges across Europe](https://news.ycombinator.com/item?id=50055304)
Attackers exploited a known Danfoss controller flaw (disclosed August) to trigger defrost cycles across Carrefour, spoiling inventory. Same vulnerability hit US military commissaries a month prior. Patch existed but operators never applied it; Danfoss calls gear "legacy" and refuses updates. Controllers were directly internet-exposed via 3G/4G SIMs with no segmentation.

### [A Modern Web App in C](https://news.ycombinator.com/item?id=50058528)
CGI stack (OpenBSD, httpd, SQLite) arguing that forking per request eliminates middleware. SQLite WAL handles concurrent reads; writes serialize but complete fast without network overhead. Thread debates pragmatic simplicity vs regression: FastCGI exists for a reason, C string handling remains painful. "Fits in your head" resonated with veterans.

### [Codex CLI installs a persistent, self-updating background daemon by default](https://news.ycombinator.com/item?id=50060694)
OpenAI's Codex CLI spawns a daemon surviving shell exit, auto-updates without consent, retains all prior versions (10+ GB). Config flag `daemon_auto_start = false` disables it but default is on. Mirrors Claude Code. Nix packagers patch both out. Daemon breaks environment inheritance and XDG compliance.

### [Turn a WiFi 7 Router into a 320 Msps SDR](https://news.ycombinator.com/item?id=50055593)
MediaTek MT7996 chipset ($80 routers) exposes test mode yielding 320 Msps IQ at 5 GHz -- exceeding typical RTL-SDR. Developer reverse-engineered firmware bring-up using LLM assistance. Unlocks 13 cm / 5 cm ham bands previously requiring expensive gear. Receive-only; transmit locked.
