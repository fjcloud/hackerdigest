## Top Stories

### [Compromised LiteLLM 1.107.0 on PyPI](https://news.ycombinator.com/item?id=50181114)
Second supply chain attack this year. Malicious wheels exfiltrate credentials and install a backdoor via compromised maintainer GitHub OAuth tokens leaked through Claude Code logging. Enterprise customers got patched builds via private registry days before public disclosure; OSS users told to pin to 1.106.2. Commenters called the pay-for-security model "strategic malpractice" -- a dependency burned twice is a wake-up call to migrate.

### [Railway Security Disclosure](https://news.ycombinator.com/item?id=50188228)
Platform breach exposed all customer environment variables. Attackers used stolen API keys (Anthropic, OpenRouter) for inference billing -- part of a pattern targeting AI providers. Railway paused deployments, leaving customers unable to rotate keys without downtime. Multiple users confirmed active key abuse. CEO acknowledged delayed communication: "we didn't want to recommend rolling keys when we couldn't confirm we'd plugged the breach."

### [DuckDB 2.0.0 LTS "Cinnamon Teal"](https://news.ycombinator.com/item?id=50181136)
Major release adds async I/O for Parquet/CSV, client-server architecture (HTTP/Arrow Flight), triggers, and multi-core scaling to 192 vCPUs (was 64). One user processes 1B record linkages in 10 minutes. Server runs in-process, staying lightweight. Triggers move DuckDB toward "data warehouse in a box."
