## Top Stories

### [Fujitsu launches made-in-Japan next-generation CPU FUJITSU-MONAKA](https://news.ycombinator.com/item?id=49715813)
Fujitsu's 144-core ARMv9 server CPU targets sovereign AI inference, with FP8 ISA extensions and 844 GB/s memory bandwidth. Commenters noted the press release buries the ARM ISA behind a single SVE2 mention. A February statement confirmed the 2nm silicon is actually fabbed by TSMC, not Japan. Shipping in Japan and Europe only.

### [Bend 2.0 -- a language that blocks AI mistakes via proof, on CPU and GPU](https://news.ycombinator.com/item?id=49746163)
Victor Taelin released Bend 2.0, a GPU-friendly language on affine dependent type theory where the AI writes laws the compiler verifies. The thread split between treating it as a real PL advance and dismissing it as vibecoded slop, with the squashed commit history not helping. Replies on the core design held up better than the optics.

### [Hacking OpenAI](https://news.ycombinator.com/item?id=49749656)
Hacktron used Claude Opus 5 in an autonomous loop to chain a libheif RCE on community.openai.com with an SSO flaw that let them open a PR against OpenAI's internal monorepo. The $6,500 bounty felt insulting given the chain could have hit GitHub, Slack, and email integrations. Buried lede: any user could have had their ChatGPT and Codex accounts taken over until two months ago.

### [CrowdSec source code leak](https://news.ycombinator.com/item?id=49742355)
CrowdSec confirmed a supply-chain attack on a TanStack dependency exposed an API key with read access to its private codebase. Top comments noted the leaked material is the SaaS console and connectors, not the open-source engine customers deploy. The bigger signal is a security aggregator failing at basic credential hygiene. One remark landed: they do not really know who is attacking them.
