### [Linux Zoom client reads X11 clipboard proactively](https://news.ycombinator.com/item?id=49675902)
Zoom's desktop client claims X11 selection ownership to keep content available, exposing everything you copy. Wayland isn't much safer either, since compositors replicate the flaw. The recommended workaround is to run Zoom in a Qubes VM or skip the native client entirely.

### [Rust stabilizes the never type](https://news.ycombinator.com/item?id=49625056)
The `!` type now sits as a proper bottom of the type hierarchy instead of a special-cased return marker, removing most `Infallible` workarounds. `Result<T, !>` lets the optimizer dead-code error handling entirely. Several commenters pushed back on `!` as syntax, arguing `Never` would read more clearly.
