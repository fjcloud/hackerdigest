## Top Stories

### [sshole](https://news.ycombinator.com/item?id=50378228)
Critical OpenSSH bug on musl libc (Alpine): any password over 256 chars authenticates as a locked account. musl returns `"*"` on hash errors instead of NULL; OpenSSH compares this against the `"*"` sentinel for disabled accounts. Alpine patched in OpenSSH 10.6p2. Commenter traced the chain: musl's error behavior + OpenSSH's timing-attack mitigation + DoS mitigation on long passwords.

### [Claude Code sends your email address to websites](https://news.ycombinator.com/item?id=50385272)
Claude Code embedded users' account emails in `User-Agent` headers of outbound HTTP requests. The email came from a system prompt block for `@author` tags; the model would "accidentally" include it in curl commands. Anthropic released a blocking plugin in 2.1.317 and will remove the email from context next week. Reported on GitHub months earlier.

### [MS Paint Remote Code Execution Vulnerability](https://news.ycombinator.com/item?id=50384233)
CVE-2026-83844: RCE in Windows 11 Paint (versions 11.0.0.0–11.2605.91.0). CVSS claims network vector, no user interaction -- likely from thumbnail rendering or Copilot integration. Fixed in 11.2609.401.0 via Microsoft Store only. Commenters noted the irony of AI features introducing a critical RCE in a drawing app.

### [The Hackintosh Reborn](https://news.ycombinator.com/item?id=50383057)
AI-assisted tooling revived Hackintosh on ARM, enabling macOS on non-Apple hardware via QEMU/KVM and Apple's virtualization framework. Commenters debated practicality: legal risk, maintenance burden, and that Apple's hardware is the real draw -- several said they'd rather run Linux on Mac hardware than macOS on commodity laptops.

### [September in Servo](https://news.ycombinator.com/item?id=50379576)
Servo added `<progress>` support, rounded rectangles, and improved Android builds. The project bans AI contributions (enforced via CI), sparking debate on whether this slows progress vs. Ladybird. Servo had 527 commits vs. Chromium's 20,000+, supplemented by full-time Igalia and Huawei contributors.
