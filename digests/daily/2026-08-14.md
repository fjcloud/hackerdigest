## Top Stories

### [Spaghettifying DRAM](https://news.ycombinator.com/item?id=49286341)
Christopher Domas returned with a DRAM aliasing exploit. By misconfiguring the AMD 16h memory controller's undocumented translation registers, ring-0 code can reach SMM, TPM, and other regions the CPU itself can't see. AMD 17h and later silently stopped documenting those registers. The thread consensus: this is the kind of full hardware access the rightful owner of a machine should already have.

### [Accelerating GPT-5.6 Sol Ultrafast](https://news.ycombinator.com/item?id=49289844)
OpenAI and Cerebras finally shipped their partnership at 750 output tokens per second with no quality compromise. The benchmark: Sol Ultrafast answered 2,500 HLE questions in 11 hours; Fable 5 needed 78 hours for the same accuracy. Pricing and consumer access remain unannounced.

### [Gemini 3.7 Flash](https://news.ycombinator.com/item?id=49289112)
Google's mid-tier model scores 56 on Artificial Analysis, up from 52 on 3.6, at half the introductory price. The sharpest thread observation: per SemiAnalysis, 20% of TPU shipments through Q4 2027 are committed to Anthropic SPVs versus ~$12B ARR for Gemini, leaving DeepMind compute-starved.

### [DeepSeek Harness developer preview](https://news.ycombinator.com/item?id=49285244)
DeepSeek open-sourced its MIT-licensed coding agent with a strict Cordis plugin system. Every plugin must declare init and teardown handlers so the runtime can hot-swap extensions mid-session. The thread's standout feature: append-only session logs capturing every prompt, reasoning trace, and tool call, unlike obfuscated Western frontier models.
