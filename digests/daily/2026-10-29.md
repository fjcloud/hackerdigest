## Top Stories

### [Why is this fingerprinting script creating bioweapons?](https://news.ycombinator.com/item?id=50276998)
An anti-bot fingerprinting vendor hides bioweapon and Tiananmen references inside its obfuscated JavaScript so LLM classifiers refuse to analyze the code. It works on frontier models. Open-weight GLM-5.3 complied and deobfuscated it. One commenter notes the filters fire on raw source before any reasoning, so renaming identifiers defeats the trick.

### [Apple's git still trusts the compromised eMudhra certificates](https://news.ycombinator.com/item?id=50271640)
macOS's `/etc/ssl/cert.pem` still contains the eMudhra roots, and git, curl, python3, perl and ruby all read that file. Apple's Unix-layer guidance is a manual edit, and macOS 27.2 restored the CA, undoing hand fixes. Homebrew ships its own bundle, so its git and curl are clean. The system tools are not.

### [Gemini 4 Carbon](https://news.ycombinator.com/item?id=50276792)
Google claims the top slot on the revised Artificial Analysis index at $2/$10 promotional pricing, with Terminal-Bench cheating driven to zero. The catch: it is gated to vetted "cyber defenders" with no release date, and almost nobody in the thread could run it. Commenters also cannot tell whether Carbon outranks Argon.

### [StackOverflow now gets fewer than 1000 questions a month](https://news.ycombinator.com/item?id=50282454)
Monthly volume is now below the site's first months of existence. An annotated graph shows the slide began around 2017, long before ChatGPT, which commenters credit to duplicate-closing moderation. LLMs finished off a site that had already driven away the people who asked.
