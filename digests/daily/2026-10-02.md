### [Pi 1.0](https://news.ycombinator.com/item?id=49926069)

Debate erupted: maintainer previously argued against MCP as a "feature" -- added it only after spec matured and GPT-family models trained on codemode. ### [Clef: Open-weight decision models](https://news.ycombinator.com/item?id=49923692)
Cloudflare released Clef (Qwen3.5-27B) and Clef-Flash (Qwen3.5-9B), open-weight Jev competitors. Thread reveals decision models are easy to replicate -- fine-tune small LLM on synthetic data with structured output. Benchmarks: Clef slower (661ms vs Jev's 230ms) and 5x pricier per decision. Real moat is calibration and eval data, not architecture.

### [Git 3.0's SHA-256 default will be a costly mistake](https://news.ycombinator.com/item?id=49924179)
Scott Chacon (GitHub cofounder) argues migration breaks ecosystem: submodules can't mix hash algorithms, commit references in docs/CI break, SHA-1 collisions remain impractical. Git docs claim bidirectional translation; commenters report real friction. Linus 2007: SHA-1 is consistency check, not security -- distribution provides trust.

### [RIP, vector database](https://news.ycombinator.com/item?id=49923466)
Turbopuffer argues pure vector DBs are wrong abstraction. v3 moves ANN to secondary index pointing at stable doc IDs (MySQL style), eliminating write amplification from reindexing on vector updates. Direct parallel to Uber's 2016 Postgres-to-MySQL migration. LanceDB and TopK already use this pattern.
