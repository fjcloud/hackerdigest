## Top Stories

### [Smart home devices should work without the internet](https://news.ycombinator.com/item?id=50441707)
Ten years of home automation: nothing core depends on a vendor's server. Consensus: Zigbee/Z-Wave + Home Assistant is the practical path; WiFi devices need custom firmware. One commenter's D-Link sensor phoned home daily and died when cloud vanished -- fixed with a Pico power-cycling it every 23 hours.

### [AlphaProof Code](https://news.ycombinator.com/item?id=50439193)
DeepMind used Gemini agents to formally verify Signal's libsignal in Lean (6M proof lines). Reintroduced known bugs to confirm detection. Skeptics note this proves security-model compliance, not absence of memory leaks -- the spec defines "correct."

### [AI usage generates a fragile codebase](https://news.ycombinator.com/item?id=50438318)
Four failure modes: shallow tests, over-engineering, readability loss, UX regressions. Thread splits: some report 500k LOC projects with zero maintenance issues; others warn of "slopocalypse" where token costs explode. Opus 5.5 landed changes in a clean codebase with higher accuracy and lower token usage than in a fragile GPT-6-generated one.

### [Tracking Anthropic-discovered vulnerabilities](https://news.ycombinator.com/item?id=50447074)
VulnCheck analyzes Glasswing: 37,966 findings, 7,349 public, 217 fixed. Curl maintainer: early reports were slop, quality improved post-spring 2026. Cloudflare: 100% triage/fix rate on proprietary code. Core tension: AI finds vulns faster than maintainers can review.
