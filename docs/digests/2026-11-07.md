## Top Stories

### [Libghostty 1.0](https://news.ycombinator.com/item?id=50399933)
Mitchell Hashimoto's terminal library hits 1.0, written in Zig with a stable C ABI. It powers Ghostty and embedders like Ghostel for Emacs. Commenters praised the API design -- opaque handles, versioned structs -- as a model for C library authors. Windows support remains community-maintained.

### [A Jev that can ask Opus for help gives Opus accuracy at 4x lower cost](https://news.ycombinator.com/item?id=50397429)
Hightouch routes identity-resolution tasks through a small decision model (Jev) that escalates to Opus only when uncertain. The pattern cut costs 4x with no quality loss. Thread discussion revealed this "model router" approach is in production at several shops; one commenter noted Anthropic's native `/advisor` flag does similar routing.

### [Firecracker VM Escape: PwnEscape Part 2](https://news.ycombinator.com/item?id=50397219)
First general-purpose Firecracker escape not requiring nested virtualization. The exploit targets a kernel networking flaw, not Firecracker itself, and the PoC runs without the jailer. AWS confirmed their deployments are not affected. Commenters debated whether microVM isolation is fundamentally sound or if the industry should shift toward formally verified microhypervisors.

### [Asahi Linux Progress Report 7.3](https://news.ycombinator.com/item?id=50401867)
Asahi announced relicensing from MIT to GPLv2+ after discovering AI-assisted forks lifting in-development code without attribution. The move sparked debate: some called it protective, others noted MIT explicitly requires attribution. Gravity Linux claims full M4/M5 support; Asahi maintainers argue upstreamable patches take longer than LLM-generated hacks.
