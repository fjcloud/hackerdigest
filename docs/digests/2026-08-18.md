## Top Stories

### [DuckDB v2.0 Preview](https://news.ycombinator.com/item?id=49330781)
v2 brings a new storage format, a stable C++ API for extensions, an extensible PEG-based parser, and a client-server mode called Quack. The thread consensus: DuckDB is rapidly encroaching on ClickHouse territory for self-hosted analytics, and teams are already using it as both engine and warehouse backend.

### [Ask HN: Alternatives to GitHub](https://news.ycombinator.com/item?id=49331033)
Triggered by GitHub's ongoing outages. Self-hosted Forgejo, Gitea, and GitLab dominated recommendations; Codeberg got love from anti-AI-tooling users. One commenter who runs self-hosted GitLab said downtime was "WAY less" than GitHub Cloud, a useful data point for anyone evaluating migrations.

### [AI-Generated GitHub Copilot Autofix Allowed Snowflake Jira Compromise](https://news.ycombinator.com/item?id=49331423)
A Copilot autofix replaced an env-var-based shell pattern with direct string interpolation, opening a classic template-injection bug that gave attackers command execution via issue titles. The takeaway from one commenter: AI makes cheap changes cheaper, but review costs haven't dropped, so the bottleneck moves to verification.

### [GPU Offload in Rust: Portable, Safe, and Fast](https://news.ycombinator.com/item?id=49334991)
Paper proposing Rust-native GPU offload via LLVM, keeping safety guarantees and targeting NVIDIA plus AMD. The obvious question in the thread: why might this succeed where LLVM's C++ offload didn't?
