### [Matrix Multiplication is Θ(n^2.25) [pdf]](https://news.ycombinator.com/item?id=50637220)
OpenAI proves matrix multiplication exponent ω = 9/4 (2.25), closing a decades-old problem (prior bound: ~2.371). Non-constructive — shows no algorithm can beat n^2.25 but doesn't provide one. Same framework also resolved Smale's 9th problem (strongly polynomial LP), parity games, and the sunflower conjecture. One commenter: first AI math result where the machinery feels genuinely novel.

### [GPT-6 demonstrates intrinsic protein-design capabilities](https://news.ycombinator.com/item?id=50634658)
