## Top Stories

### [DeepInfer: High-performance inference framework for DeepSeek models](https://news.ycombinator.com/item?id=50163277)
DeepSeek open-sourced their production inference engine: 155T tokens/day per cluster at $38/card/hr. Supports NVIDIA SM100 and Huawei Ascend 950. At $35/hr net, a $30K GPU pays off in ~35 days. Commenters called this "strategic sabotage" against closed-model moats -- open inference + Chinese hardware + open weights = race to bottom on pricing. KV cache (72-hr retention) and disaggregated prefill/decode absent.

### [eMudhra intermediate CA compromise](https://news.ycombinator.com/item?id=50166579)
Eight eMudhra intermediate CAs had private keys so weak they're single-byte values (one is literally "4"). Script bug during HSM testing generated weak keys accidentally used for CSRs signed by eMudhra's root and Sectigo. Browsers with CRLite protected; curl, IoT, most non-browser clients vulnerable. Any domain impersonatable. Mozilla/Google revoking root; CA faces ejection.

### [Upcoming critical PHP security release (CVE-2026-109618 / -109619)](https://news.ycombinator.com/item?id=50172041)
Emergency patches for all PHP 5-8 dropping tomorrow. Exploit circulating -- PoC shows arbitrary shell via multipart upload. Cloudflare WAF has mitigations; Alpine has patched builds. PHP core devs say mitigations insufficient. Several sites (OpenStreetMap, vogons.org) offline preemptively.
