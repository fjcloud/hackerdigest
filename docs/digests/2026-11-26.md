## Top Stories

### [1Password Security Incident](https://news.ycombinator.com/item?id=50644817)
An attacker compromised an employee's GitHub account and pushed malicious code to production, downloading customer admin data. The breach illustrates a systemic SaaS risk: as headcount grows, a compromised laptop becomes inevitable, and if that account can deploy code, the service is owned.

### [Holy shit holy shit holy shit holy shit: The magnitude of what's now happening](https://news.ycombinator.com/item?id=50646108)
Scott Aaronson surveys AI-driven math breakthroughs: matrix multiplication exponent ω = 9/4 proven, GRH formalized in Lean, Navier-Stokes and RH claims circulating. Results are non-constructive but the pace is unprecedented — one commenter likened this to the shift from hunting elements in ores to synthesizing them in cyclotrons.

### [Google releases Cogentic papers on integer factorization, discrete logs](https://news.ycombinator.com/item?id=50642086)
Google's multi-agent system produced new asymptotic bounds: factorization in L_N[1/3, 105], discrete logs with logloglogn improvement. None are practical — GNFS still wins by massive constants — but they prove AI can reliably match or beat the best *proven* classical bounds.

### [Much shorter version of GRH Lean verification from Anthropic](https://news.ycombinator.com/item?id=50648050)
Anthropic compressed the 17M-line GRH Lean proof to 76k lines (99.56% reduction), with a readable 300k-line version also available. The community-driven effort achieved only 33% reduction after months — internal models did in days what hundreds of humans couldn't.
