## Top Stories

### [AI made self-hosting fun again](https://news.ycombinator.com/item?id=50660180)
AI tooling lowered the friction of spinning up self-hosted services, but the security burden accelerated from "update every few months" to "patch within 24 hours of a CVE9+ drop." Consensus defense: hide everything behind Wireguard/Tailscale/Cloudflare tunnels and let AI agents automate patching. One commenter built a root-permissioned agent that continuously monitors CVEs and patches live — a security nightmare they're "starting to come around to" for non-critical servers.

### [AMD-specific fork of llama.cpp](https://news.ycombinator.com/item?id=50657265)
Hardware-specific forks (Strata, Radiance, Hipfire) deliver 2-3x speedups on AMD GPUs by targeting specific models (Qwen, Inkling) and architectures (RDNA3, gfx906). Tradeoff: some forks degrade quality by polling VRAM-resident experts instead of correct ones. Llama.cpp's PR review latency (months) drives fragmentation; community wishes these optimizations would upstream.

### [Google Will Make AI Agents Use Its MCP Servers](https://news.ycombinator.com/item?id=50653477)
Google's Gmail MCP server supports reading and drafting but not sending email — widely viewed as protecting ad revenue, not safety. Anthropic's Claude connector retains send capability. Fastmail's MCP server (open, no partner restrictions) gets strong praise. Terms also ban retaining user data after disconnect, killing backup and accounting integrations.
