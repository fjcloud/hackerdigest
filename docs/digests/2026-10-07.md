### [Counterfeit TLS certs via ccTLD registry hijacks](https://news.ycombinator.com/item?id=49988230)
Attackers compromised .gh, .sl, .as registries, got valid Let's Encrypt certs for google.gh/sl/as. Chrome detected via CT logs in hours. Root cause: CAA records live in DNS, so registry compromise = cert issuance compromise. HPKP (deprecated) would have prevented; CAA with ACME bindings helps but isn't universal.
