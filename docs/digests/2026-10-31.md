## Top Stories

### [Northflank breached](https://news.ycombinator.com/item?id=50305025)
A PaaS vendor selling agent sandboxes disclosed a breach; customers spent the day rotating API keys and deploy secrets. The best technical point: PaaS products must display env vars back to users in the management UI, so compromising that tier hands over every tenant's credentials. Commenters count six such breaches since September.

### [Google's Sleep framework for continual learning](https://news.ycombinator.com/item?id=50272479)
Google's preprint gives a model a short-term memory buffer, then a "sleep" phase ranks those memories and folds the useful ones into weights via low-rank and MoE updates, plus a "dreaming" pass of synthetic self-training. The doubt in the thread is scale: tests use Llama 3B/8B and Qwen, where gains come cheap.

### [Tangled's federated code forge](https://news.ycombinator.com/item?id=50305573)
Tangled, a git forge built on AT Protocol, relaunched with stabilized lexicons, organizations, and self-hosting of individual components; private repos are weeks out. The co-founder says issues and PRs now live as git objects inside the repo and are projected as ATProto records, making a knot server PDS-like.

### [Cisco bets its codebase on one engineer](https://news.ycombinator.com/item?id=50304122)
Cisco's president gave a 27-year-old engineer unlimited model tokens to rewrite 98% of its legacy code. The objection in the thread is not that AI can't write code, but that old code encodes decades of undocumented bug fixes and interop quirks. A former IOS-XR engineer calls it a vanity project.
