## Top Stories

### [Goldman Sachs is pulling Claude Code from its bankers and traders](https://news.ycombinator.com/item?id=50415628)
Goldman restricted Claude Code and Copilot to engineers only, citing the "lethal trifecta" of agents on workstations with client data, email, and internal network access. Thread consensus: this followed a material incident. Traders passed vibe-coded tools to 12,000 engineers to "improve" -- meaning rewrite. Barclays moves oppositely, giving Claude Code to half its developers while cutting 5,000 jobs.

### [Goodbye Claude, hello Pi](https://news.ycombinator.com/item?id=50410107)
A developer documents switching from Claude Code to Pi, a hackable coding harness. Discussion reveals a fragmented ecosystem: Pi, Opencode, DeepSeek Harness with different tradeoffs on compaction, caching, subscription compatibility. Key insight: Anthropic's 244 releases this year (3/4 changing system prompts) create instability; Pi users value total control over the agent loop. Several run local models (Qwen 3.8, GLM) on 128GB Macs for "good enough" coding at zero marginal cost.

### [Declarative Dragging](https://news.ycombinator.com/item?id=50368481)
Research replacing imperative drag-and-drop with a declarative algebra: specify drop targets, system speculatively renders valid end states and interpolates. Built on Hazel (live programming environment), uses a combinator language over distance predicates. Paper argues this eliminates the "speculative live editing" complexity that makes drag-and-drop notoriously hard. One commenter called the API "as significant as Reactive Extensions."
