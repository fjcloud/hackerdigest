Discussion around LLM use keeps returning to a practical multiplier: experts frame problems, catch plausible errors, and steer toward useful abstractions. The strongest comment reframed it as verifiability: mathematics can check itself, while production code and most domain answers still need an expert.

### [ClickHouse turns database research into a product-adjacent lab](https://news.ycombinator.com/item?id=49156011)
