## Top Stories

### [Passkeys are a trap](https://news.ycombinator.com/item?id=50048312)
Critique argues passkeys trade user control for convenience via WebAuthn attestation. Sites can eventually require hardware-backed, non-exportable credentials locking users into approved platforms. Thread's best insight: "boil the frog" playbook -- optional feature becomes default, opt-out moves to advanced settings, then disappears.

### [Total Annihilation, rebuilt for modern computers](https://news.ycombinator.com/item?id=50045984)
Clean-room rewrite of the 1997 RTS in Go using Ebiten, derived from static analysis of the original binary. Documents original data formats; claims 60fps at 64k units. Thread debates whether LLM-assisted "clean room" holds legal weight; Compaq's BIOS clone set precedent but LLM decompilation is untested.

### [NYC's "Click to Cancel" rule is now in effect](https://news.ycombinator.com/item?id=50045946)
NYC mandates cancellation be as easy as signup -- same medium, same steps. FTC attempted federal rule in 2024; killed by Eighth Circuit. Thread consensus: companies will geofence compliance rather than make it easy everywhere, revealing the deliberate choice to keep dark patterns.

RDS r8g to r8gd dropped avg I/O from 1ms to 0.1ms. Cloud abstractions hide hardware reality; local NVMe instances win for latency-sensitive workloads.
- **[No portable way to detect string-to-float conversion errors in standard C](https://news.ycombinator.com/item?id=50034001)** -- `strtod` error detection is implementation-defined; errno + endptr checks fail across locales. `std::from_chars` (C++17) solves it; C23 adds `typeof` for ergonomic result structs.
