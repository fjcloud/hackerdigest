## Top Stories

### [Qwen Image 2.1](https://news.ycombinator.com/item?id=49775499)
A 7B-parameter open-weight image model with native RGBA transparency and strong text rendering. The license shifted to non-commercial only, a regression from earlier Apache releases. One tester found small-text fidelity materially better than gpt-image-2 in side-by-side runs.

### [Samsung to double HBM4 output](https://news.ycombinator.com/item?id=49778029)
Capacity comes from redirecting existing DRAM lines, not new fabs. Commenters noted consumer RAM will stay expensive since HBM uses roughly 3x the wafer area per byte of standard DRAM. The real bottleneck for China's accelerator buildout is HBM packaging equipment, not processors.

### [Google's AX agent orchestrator](https://news.ycombinator.com/item?id=49780797)
Apache 2.0 control plane for coding agents on Kubernetes with microVM sandboxes, fast resume, and a MITM gateway for LLM provider calls. Reception split between "table stakes for every agent stack" and "YAML hell with extra steps." Naming collisions with Meta's Ax and AxLLM drew repeated flags.

### [Spain orders blocks on Archive.today](https://news.ycombinator.com/item?id=49772961)
Major Spanish ISPs complied with IP-blocking orders across Archive.today and its mirrors. Same mechanism Spain uses to take down CDN ranges during La Liga matches. Commenters in Spain confirmed the block on Vodafone and Orange; Starlink still reaches the site.

## Projects & Tools

- **[RE4 (GameCube) byte-identical decompilation](https://news.ycombinator.com/item?id=49778022)** -- Resident Evil 4 reverse-engineered back to C/C++ matching the original binary. The 644 `// COMPILER-DIFF:` markers drew criticism: one commenter argued byte-matching is Goodhart's law, with asm() register pins showing the source wasn't truly recovered.
- **[Amiga Unix, Again](https://news.ycombinator.com/item?id=49781436)** -- AI-assisted attempt to resurrect Commodore's SVR4 port on real Amiga hardware. Commenters noted NetBSD still supports Amiga, making this more nostalgia than a real OS gap.
