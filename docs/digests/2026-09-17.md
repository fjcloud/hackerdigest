## Top Stories

### [Nvidia announces native GPU programming in Rust](https://news.ycombinator.com/item?id=49724881)
Two tracks land: a SIMT-compatible `cuda-oxide` layer requiring nightly Rust, and a Tile-based track with a stable compiler. Co-developed with Vectorware. Multiple commenters flagged the blog post as fully Claude-written, and one noted Rust async/autodiff still won't go stable in 2026.

### [AWS can't restore some Mideast data after multiple Bahrain AZs are knocked out](https://news.ycombinator.com/item?id=49719249)
AWS confirmed all three AZs in me-south-1 (Bahrain) were damaged beyond what multi-AZ redundancy was designed for. One commenter resurfaced a recent CBS interview where an AWS exec promised "you wouldn't notice" if a single data center were blown up, now likely destined for a lawsuit. The thread agrees cross-region replication plus offline cold storage are the only real defenses against missile-scale events.

### [Training a 4B model to produce 81% faster query plans than Postgres](https://news.ycombinator.com/item?id=49731285)
A fine-tune on frontier-planner trajectories yielded a 1.81x geometric mean speedup on an 8GB in-memory join-heavy workload. Experienced DBAs pushed back hard: the test ignored planner time and used no extra indexes or stats, so per-query model inference isn't really "free." A vocal minority argued classic ML ranking models beat LLMs for this problem.
