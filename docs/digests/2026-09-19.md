## Top Stories

### [Android 17 ships new APIs without AOSP](https://news.ycombinator.com/item?id=49758736)
GrapheneOS flagged that Google added new APIs in Android 17 QPR1 without releasing to AOSP -- a first since Honeycomb 3.x. A project reply in-thread clarified the deeper concern: Pixel-only quarterly releases now contain security content not appearing in OEM backports. Commenters split between AOSP's slow collapse and Google simply losing its grip on Android.

### [Saving another 100TB of RAM at Cloudflare](https://news.ycombinator.com/item?id=49758580)
Follow-up to the consistent-hashing series: a derivation proved fewer bits sufficed for load balance, letting Cloudflare shrink a per-server hash from 4 bytes to 2. The Rust struct change is trivial but yielded 100TB of fleet memory back. One top commenter argued the article patches up flaws in a solution more complicated than the straightforward one.

### [ZCode harness silently uploads full Git history](https://news.ycombinator.com/item?id=49750694)
Z.ai's closed-source ZCode agent was caught snapshotting and uploading entire user workspaces -- including ignored files -- encrypted with a key the user never held. z.ai apologized, blamed a codebase-indexing feature, and committed to open-sourcing ZCode. Top reply: envelope encryption with server-held keys turns local backup into remote asset extraction.

### [Photon-guided laser fault injection breaks RP2350 secure debug](https://news.ycombinator.com/item?id=49757050)
Ledger's Donjon used a $250K photon-emission microscope to flip a single bit in the RP2350 OTP and bypass the bootloader lockdown. Commenters noted the gear cost is overstated -- the same single-bit flip can be brute-forced for far less, and most hardware labs already own most of the kit.
