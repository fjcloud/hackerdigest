## Top Stories

### [Introducing System One Models and Jev](https://news.ycombinator.com/item?id=49717558)
A stealth startup called TypeSafe unveils "Jev," a model that outputs only structured decisions in a single forward pass. No autoregression, no string generation, no output token cost. The Doom demo won over several skeptics, though commenters pushed back on framing structured decisions as comparable to text generation.

### [An update on Wayback Machine access](https://news.ycombinator.com/item?id=49716176)
The Internet Archive blames recent 429 errors on AI scrapers using the Wayback Machine as a fallback for sites that block direct crawls. Commenters noted paid scraper APIs already advertise "Wayback fallback" as a feature, and publishers are starting to opt out entirely. The thread points at Web Bot Auth and robots.txt v2 IETF drafts as a real path forward.

### [Building a Linux GPU Driver for the M4 Mac Mini in One Month](https://news.ycombinator.com/item?id=49717638)
A former Apple engineer used heavy LLM help to write a working GPU driver for the M4 Mac Mini. The post ignited a fight over Asahi's clean-room, no-LLM policy and whether ex-Apple status disqualifies upstreaming. A Reddit mod claimed the author was banned from Asahi for hiding prior affiliations. He denied that explicitly.
