## Top Stories

### [Levent Alpöge claims proof of the Generalized Riemann Hypothesis](https://news.ycombinator.com/item?id=50574968)
Anthropic mathematician Levent Alpöge posted a 250,000-page Lean-formalized proof of GRH, crediting Claude for "flying, dancing, and sparkling" past the finish line. Also resolves Extended and Grand RH. Thread consensus: if verified, biggest math day since Wiles. One commenter noted the human guided the AI to the right "toy setting" — the AI then outpaced the mathematician entirely.

### [Language Models Can Rewrite Their Own Weights](https://news.ycombinator.com/item?id=50577265)
Paper demonstrates an LLM iteratively editing its own weights via reasoning — no gradients, no backprop — improving accuracy over eight sessions by fixing token-limit loops. Skeptics note the only fix shown was clipping outlier activations (known abliteration). One commenter called this "negentropy" from test-time compute, not a phase shift; another warned autonomous weight editing bypasses alignment by design.

### [Inkling 2 Mini: Looped MoE model for local inference](https://news.ycombinator.com/item?id=50581260)
Thinking Machines releases a 26B MoE (3.6B active) looped transformer running three passes per token (~5.4B effective params). Beats Qwen 3.8 27B on benchmarks, trained in NVFP4, quantizes to 1-bit with 90% quality retention. Runs ~20 tok/s on M1 Max. Commenters note looped architectures trade memory for compute — ideal for bandwidth-constrained GPUs — but Terminal Bench scores are weak.

### [Valkey replaces skiplists with B+ trees, cuts sorted set overhead 43%](https://news.ycombinator.com/item?id=50534387)
Valkey migrates sorted sets from skiplists to B+ trees, citing cache unfriendliness on modern hardware. Benchmarks show 43% memory reduction and latency improvements. Thread discussion: B+ trees are inherently cache-friendly; skiplists favor concurrent writers. AWS discounts Valkey 20-35% vs Redis.
