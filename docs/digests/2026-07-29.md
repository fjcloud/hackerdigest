## Top Stories

### [Codex Security](https://news.ycombinator.com/item?id=49089755)
OpenAI open-sourced Codex Security, a closed plugin extended by the team from Promptfoo. It mostly wraps existing models, with skill definitions and CI scaffolding as the actual product. Commenters burned through weekly Pro quotas on silent scans, and the maintainer admitted the cost controls are inadequate.

### [Kimi K3 Architecture Overview and Notes](https://news.ycombinator.com/item?id=49085698)
Sebastian Raschka's notes on Moonshot's Kimi K3 highlight an aggressive NoPE design. Kimi Delta Attention layers carry position via recurrence instead of RoPE in attention layers. Thread consensus: KDA is essentially an efficient RNN, and implicit positional signal comes from accumulated residual state through causal masking.

### [Discovering Cryptographic Weaknesses with Claude](https://news.ycombinator.com/item?id=49087091)
Anthropic used Claude to find best-known attacks on 7-round AES-128 and the HAWK post-quantum candidate, halving HAWK's effective key length at roughly $100k per result. Commenters noted neither breaks production crypto. The stranger detail is the typo-laden, oddly grumpy prose researchers used to push Claude toward harder targets.

### [Zig's Incremental Compilation Internals](https://news.ycombinator.com/item?id=49085666)
Zig engineer mlugg walks through the incremental compiler and linker: dep graphs at the ZIR level, in-place ELF binary patching, and a deliberate ban on cross-function inlining. A rust-analyzer maintainer added: Rust's query-based system can't match this granularity because the type system forbids the simpler dep tracking.
