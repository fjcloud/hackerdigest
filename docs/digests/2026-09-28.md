### [When did Google get so weird?](https://news.ycombinator.com/item?id=49870367)

### [Owed a billion dollars in Nvidia stock](https://news.ycombinator.com/item?id=49872723)

### [Ember-1](https://news.ycombinator.com/item?id=49868830)
Fireworks AI released Ember-1, a Kimi K3 derivative matching frontier performance on "Bedside Bench" with half the reasoning tokens. Debate: genuine efficiency or benchmark-chasing? Model isn't open-weight despite open research; pricing matches K3 despite fewer tokens. Techniques likely generalize to other reasoning models.

### [Don't couple your Go code to GitHub](https://news.ycombinator.com/item?id=49868404)
Go's import paths embed the hosting domain, making migration painful. Article advocates vanity domains with nginx redirects; thread adds `go.mod` replace directives handle migration but don't help downstream users. Key insight: Google's module proxy caches packages immutably -- real risk is domain abandonment.
