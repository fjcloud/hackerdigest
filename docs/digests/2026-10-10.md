### [Cloudflare acquires Deno](https://news.ycombinator.com/item?id=50019911)

### [Oxide Computer raises $445M Series D](https://news.ycombinator.com/item?id=50020014)
On-prem cloud hardware company raises third massive round in 15 months (B: $100M, C: $200M, D: $445M). Vertically integrated racks deliver cloud UX on customer premises. Profitable. "No GPU" debated; consensus: CPU workloads still dominate AI pipelines. Open-source control plane runs on commodity hardware.

### [Telegram Desktop: one-click file exfiltration and account takeover](https://news.ycombinator.com/item?id=50029123)
A custom `tg:` URL scheme for publishing releases exposed an "upload any file" endpoint. Clicking a malicious link exfiltrated arbitrary files (including message DB) and enabled account takeover. Fixed now. Feature was "plausibly deniable" -- an insane implementation that looks like a backdoor. Sandboxing would have contained it.

### [REA Reverse – AI-assisted reverse engineering](https://news.ycombinator.com/item?id=50028275)
Wraps Ghidra, radare2 into an agent harness. LLMs drive decompilation, rename functions, trace control flow, produce matching recompilations. Touhou 4 decompiled in a month with sensible names. Debate: eliminates hobby or just grunt work? Opus 5.5 refuses DRM work; GLM and Codex 6.1-Sol more permissive. Suspicious fork rate (19% of stars).
