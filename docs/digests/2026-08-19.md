## Top Stories

### [Memory prices climb 500% in 12 months](https://news.ycombinator.com/item?id=49334960)
128GB of DDR5 now hits $3,399. The thread's sharpest data point: OpenAI's Stargate project locked up 40% of global DRAM output a year ago, and new CXMT capacity won't ease the squeeze until late 2027. One commenter is holding out hope their 10-year-old desktop will survive the crunch.

### [Cursor launches Origin, GitHub alternative](https://news.ycombinator.com/item?id=49334209)
Cursor's hosting platform dropped days after GitHub's latest outage. Commenters are skeptical, citing the tight Cursor integration, the lack of public repos, and the recent Grok incident where its code agent uploaded users' entire codebases. The recurring suggestion: stay on self-hosted Forgejo.

### [Cerebras CS-4](https://news.ycombinator.com/item?id=49354949)
Rack-scale inference targeting 30x the GPU throughput and 10x per-watt over CS-3. The consensus: chip designers are only a few iterations into AI-optimized silicon, so the current GPU-heavy build-out may look quaint in five years. Power consumption figures are conspicuously absent from the launch materials.

### [Fixing a bricked Framework laptop](https://news.ycombinator.com/item?id=49345220)
Author resurrected an AMD 7040 Framework 13 bricked by a botched BIOS flash using a $5 CH347 programmer and pogo pins. The deeper complaint: Framework's support pointed him at a CA$500 motherboard, while $70 desktop mainboards have offered USB-based crash-free BIOS recovery for years.

## Projects & Tools

- **[Turbovec](https://news.ycombinator.com/item?id=49349898)** -- Rust port of Google's TurboQuant for vector search, fitting 10M documents in 4GB with log-scale deletion latency. Commenters noted RaBitQ already ships a similar scheme in production.
- **[machine0 (YC S26)](https://news.ycombinator.com/item?id=49348136)** -- Persistent CPU and GPU VMs with a minimal CLI (`new`, `ls`, `rm`) and native NixOS support, aimed at long-running agent fleets on DigitalOcean infra.
- **[Solo](https://news.ycombinator.com/item?id=49354613)** -- A .so loader you can embed into a statically linked Linux binary so it can dlopen glibc-built shared libraries like Vulkan drivers. Useful for shipping musl binaries that still need GPU access.
